# Задачка дня на истории

## Зачем

Короткий ежедневный повод зайти в Mini App и потренировать чтение графика без риска
для портфеля. Потом на неё ляжет серия дней (streak).

## Что видит игрок

Карточка наверху вкладки «Учёба»: 60 свечей 5m из прошлого без названия пары и дат,
три кнопки «Лонг», «Шорт», «Пропустить». После ответа на графике дорисовываются
следующие 12 свечей (час), показываются пара, движение цены в %, тренд по EMA и RSI
в момент среза, короткое пояснение и ссылка на урок про тренд (06) или RSI (07).
За верный ответ 20 XP. Ответ один, переиграть нельзя.

## Решения

- **Источник — автоматически из истории (выбор пользователя), одна задачка на всех на
  UTC-день.**
- Задачка создаётся лениво при первом запросе за день и сохраняется в `daily_puzzles`
  (уникальный день). Планировщик не нужен; гонку двух запросов закрывает уникальный
  ключ и повторное чтение. *(моё решение)*
- Выбор окна детерминирован от даты (seed = день): пара из стартовых, срез в последних
  30 днях, но не ближе 2 дней к сегодня. Пробуем до 50 срезов, берём первый
  с понятным исходом. С вероятностью 1/4 ищем флэт (ответ «пропустить»), иначе
  движение. *(моё решение)*
- Исход по close через 12 свечей: |движение| ≥ 0.5% → лонг/шорт; < 0.2% → пропустить;
  промежуточные срезы пропускаем, чтобы ответ был однозначным. *(моё решение)*
- Время свечей в ответе до ответа сдвинуто на фиксированную базу, чтобы срез нельзя
  было найти по дате на внешнем графике. *(моё решение)*
- Пояснение собирается на фронте из i18n-шаблонов по числам (тренд, RSI, движение),
  без LLM. *(моё решение)*
- Ответы в `puzzle_answers` (уникальны по игроку и дню), XP через `award_xp`,
  событие `puzzle_done`. *(моё решение)*
- Если истории мало и окно не нашлось, API отдаёт `{"puzzle": null}`, а карточка
  не показывается.

## Подходы

- **А. Авто из истории** — выбран: нет ручной работы, задачки не кончаются.
  Пояснения шаблонные.
- Б. Вручную в `content/` — качественнее, но эпизоды быстро кончатся.
- В. Смесь — можно добавить позже поверх А, если шаблонов не хватит.

## Не делаем сейчас

Серия дней, сравнение с друзьями, уведомление о новой задачке, архив прошлых задачек.
