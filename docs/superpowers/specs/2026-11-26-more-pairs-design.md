# Новые пары: уровни 11–15 и Pro-пары

## Зачем
Больше контента для привлечения и удержания: опытным игрокам есть куда расти
после 10-го уровня, а Pro получает видимую «фишку» — эксклюзивные пары.

## Approaches
1. Раскидать новые пары по уровням 2–10 — просто, но не добавляет прогрессии.
2. Уровни 11–15 с новыми парами — растягивает прогрессию, новичков не грузит.
3. Эксклюзивные пары только для Pro — монетизация, но без привлечения.

Выбрано (пользователь): **2 + 3 вместе**.

## Решения
- **TON → AAVE** на 5-м уровне: TON на Binance в статусе BREAK (торги стоят),
  открытых позиций по TON 0.
- Все новые пары торгуются и на Binance, и на Bybit (Bybit — резервный фид;
  неизвестный топик ломает подписку). Поэтому ZEC/TAO/PAXG не берём, золото — XAUT.
- **Уровни 11–15**, XP: 4000, 4900, 5900, 7000, 8200 (шаг растёт на 100, как раньше):
  - 11: HYPE, ENA · 12: ARB, OP · 13: WLD, FET · 14: INJ, SEI · 15: RENDER, HBAR
- **Pro-пары** (с любого уровня, пока активен Pro): XAUT (золото), WIF, BONK, TRUMP.
  - Бесплатный игрок видит их в списке пар с замком «Pro»; тап ведёт в `/pro`.
  - Pro истёк — открытые позиции можно закрыть (замок проверяется только при открытии).
  - ИИ их не торгует (`AI_SYMBOLS` без изменений).
- **Worker сам перезапускается**: если от Binance нет котировок 5 минут, процесс
  выходит с ошибкой, Docker поднимает его снова (`restart: unless-stopped`).
  Причина: 2026-11-26 контейнер потерял DNS и не восстановился сам.

## Что затронет
`app/game/config.py` (списки пар, `LEVEL_XP`, `PRO_SYMBOLS`),
`players.unlocked_symbols` (+ `now_ms`, Pro-пары) и оба вызова в `game_routes.py`,
`/game/quotes` отдаёт `pro_symbols`, Mini App (замок + i18n RU/EN),
`app/worker.py`, тесты `test_config`, `test_progress`, `test_worker`.
